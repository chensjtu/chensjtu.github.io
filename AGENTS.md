# Repository Notes

This is Chen Yang's static academic homepage hosted with GitHub Pages.

## Main Files

- `index.html`: English homepage and default entry.
- `index_zh.html`: Chinese homepage.
- `global.css`: Shared styles for both pages.
- `cv_en.pdf`: English CV.
- `cv_zh.pdf`: Chinese CV.

## Editing Guidelines

- Keep the English and Chinese pages structurally consistent.
- When updating personal information, news, projects, or highlights, update both language versions.
- Keep paper titles, author lists, venue names, and terms such as `Oral` in English.
- Translate descriptive text and interface labels on the Chinese page.
- Reuse the existing static HTML/CSS/JavaScript patterns; no build step is required.
- Do not remove or replace media assets unless explicitly requested.

## Verification

- Check that local `href`, `src`, video, PDF, and model paths exist.
- Verify that language-switch links work in both directions.
- Preserve the existing collapsible sections and their `data-target`/`data-collapsible` values.
